**Classic & Cut** es una experiencia de grooming premium diseñada para el hombre moderno que valora el legado de la tradición. Desde 1924, perfeccionando el arte de la caballerosidad.

## ✨ Características

- **Diseño Luxury & Moderno**: Interfaz oscura con acentos dorados, tipografía premium y animaciones sutiles.
- **Reserva Online**: Integración con **Calendly** para agendar citas de forma sencilla.
- **Mapa Interactivo**: Localización exacta mediante **Leaflet**.
- **Contacto Directo**: Botón flotante de **WhatsApp** para atención inmediata.
- **Responsive Design**: Totalmente optimizado para móviles, tablets y escritorio.

## 🛠️ Tecnologías

- [Vite](https://vitejs.dev/) - Frontend Tooling
- [Tailwind CSS](https://tailwindcss.com/) - Framework de CSS
- [Leaflet](https://leafletjs.com/) - Mapas interactivos
- [Google Fonts](https://fonts.google.com/) - Tipografías (Manrope, Inter)
- [Material Symbols](https://fonts.google.com/icons) - Iconografía

## 🚀 Inicio

1. **Clonar el repositorio**
   ```bash
   git clone <url-del-repositorio>
   cd barbershop
   ```

2. **Instalar dependencias**
   ```bash
   npm install
   ```

3. **Ejecutar en modo desarrollo**
   ```bash
   npm run dev
   ```

4. **Construir para producción**
   ```bash
   npm run build
   ```
